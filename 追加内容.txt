加密
上次更新时间: 2025-02-13

IBM OpenPages® 支持以下可选功能:

    您可以配置定制加密密钥以加密存储在 OpenPages 属性文件中的密码。

    如果未配置定制加密密钥，那么属性文件中的密码仍会加密。 但是，您的组织策略可能要求您使用定制加密密钥。
    您可以对 IBM OpenPages 存储库中的特定字段进行加密，以防止系统管理员直接从数据库查看机密数据。

    创建密钥库
    您可以为 IBM OpenPages创建密钥库。
    为属性文件中的密码配置定制加密密钥
    您可以配置定制加密密钥以对属性文件中存储的密码进行加密。
    配置字段级别加密
    您可以对 IBM OpenPages 存储库中的特定字段进行加密，以防止系统管理员直接从数据库查看机密数据。 加密字段中的数据显示为一串随机字符。
    更新加密密钥库
    贵公司的 IT 策略可能要求您定期更改加密密钥。 每当加密密钥详细信息更改时，都必须更新 IBM OpenPages中的加密密钥库。
    加密服务器变量
    您可以使用管理应用程序服务器上的环境变量来配置用于AES加密的密码模式，并启用或禁用 3DES 加密的初始向量（IV）随机化。 这些设置会影响字段级加密和属性文件中的密码加密。

创建加密密钥库文件和密钥对
上次更新时间: 2025-02-13
必须先创建包含密钥对详细信息的加密密钥库文件，然后才能在 IBM OpenPages®中设置加密密钥库。

该文件必须使用 Java™ 格式 (jceks)。 虽然可以使用任何密钥工具来创建文件，但它必须使用与 Java 密钥库相同的格式。
加密密钥必须使用下列其中一种加密算法。 不支持任何其他算法。
表 1. 受支持的加密算法
算法名称
	
密钥大小
3DES	168
AES128	128
AES192	192
AES256	256
运行 keytool -genseckey 命令时，系统会提示您输入密钥库密码和密钥密码。
重要信息: 必须对密钥库和密钥使用相同的密码。

在以下示例中，该命令将生成使用受支持 Java 格式 (jceks) 的密钥库。 加密密钥使用密钥大小为 168 的 3DES 加密算法。

keytool -genseckey -alias openpages -keyalg 3DES -keysize 168 
 -storetype jceks -keystore keystore-3DES.jks

在以下示例中，该命令将生成使用受支持 Java 格式 (jceks) 的密钥库。 加密密钥使用密钥大小为 256 的 AES 加密算法。

keytool -genseckey -alias openpages -keyalg AES -keysize 256
 -storetype jceks -keystore keystore-AES256.jks

设置加密密钥库
上次更新时间: 2025-09-26
加密密钥库是一个文件，用于存储用于加密存储在属性文件中的密码以及用于加密 IBM OpenPages® 存储库中的数据的密钥。
开始之前
您需要密钥库文件，并且需要知道密钥库密码。 有关更多信息，请参阅 创建加密密钥库文件和密钥对。
过程

    启用系统管理方式。
    有关更多信息，请参阅 启用和禁用系统管理方式。
    单击 打开管理菜单 管理菜单 > 用户和安全性 > 加密密钥存储.
    单击 编辑。
    在 密钥名称 字段中输入加密密钥的名称。
    在 密钥别名 字段中输入别名。
    重要信息: 确保指定的别名与密钥库文件中的别名完全匹配。
    在 密钥库位置 字段中输入密钥库位置。

    出于安全原因，您无法浏览到该位置，必须手动输入该位置。
    在 算法 字段中选择密钥所使用的加密算法。
    在 密钥库密码 字段中输入密钥库密码，
    重要信息: 确保此处指定的密码与密钥库文件中的密码完全匹配。
    在 重新输入密钥库密码 字段中确认密码。
    在 描述 字段中输入密钥库的描述。
    单击 更新。
    注: 如果将来更改任何这些密钥库属性，那么必须更新密钥库。 有关更多信息，请参阅 更新加密密钥库。

keystore.properties 文件
上次更新时间: 2025-02-13
创建 keystore.properties 文件。 该文件定义要用于存储在 IBM OpenPages® 属性文件中的密码的定制加密密钥。

在 IBM OpenPages中创建密钥库并对其进行配置之后，请执行此任务。
使用以下文本作为模板:

#Tue December 13 23:35:46 EDT 2018
key.password=<password for the encryption key>
key.alias=<alias (name) of the encryption key>
keystore.path=<full path to the .jks file> 
store.password=<password for the keystore>

注: key.password 和 store.password 必须相同。
对于 keystore.path 参数，请使用所有应用程序服务器和报告服务器都可访问的目录。 如果使用全局搜索，请确保搜索服务器也可以访问该目录。 您可以选择以下选项：

    指定所有应用程序服务器，报告服务器和搜索服务器可访问的网络位置。
    或者，将 .jks 文件存储在每个服务器上的同一目录中。
    或者，为每种类型的服务器创建 keystore.properties 文件。

示例：

#Tue December 13 23:35:46 EDT 2018
key.password=password
key.alias=openpages
keystore.path=C\:\\admin\\keystore-AES128.jks 
store.password=password

更新应用程序服务器上的属性文件以使用定制密钥
上次更新时间: 2025-02-13
配置定制加密密钥后，请更新应用程序服务器上的属性文件以使用定制加密密钥。
开始之前
必须先完成以下任务，然后才能开始:

    创建包含加密密钥库和密钥对的文件。 请参阅 创建加密密钥库文件和密钥对。
    设置加密密钥库。 设置加密密钥库
    创建 keystore.properties 文件。 请参阅 keystore.properties 文件。
    验证所有应用程序服务器都可以访问 keystore.properties 文件中指定的 keystore.path 。

过程

    停止所有 OpenPages 应用程序服务器，管理和非管理。
    请参阅 停止应用程序服务器。
    将 keystore.properties 文件复制到 <OP_HOME>/aurora/bin 目录。
    编辑 aurora.properties 文件。
        转至 <OP_HOME>/aurora/conf 目录。
        生成 aurora.properties 文件的备份副本。
        在文本编辑器中打开 aurora.properties 文件。
        将等号后的以下密码值更改为纯文本。

        security.system.password=<openpages_system_password>
        database.PASSWORD=<openpages_db_password>
                             

        保存并关闭文件。
        稍后在此任务中重新启动服务器时，将使用定制加密密钥对密码进行重新加密。
    编辑 aurora_auth.config 文件。
        转至 <OP_HOME>/aurora/conf 目录。
        生成 aurora_auth.config 文件的备份副本。
        在文本编辑器中打开 aurora_auth.config 文件。
        找到 security.search.user.credentials 参数
        将等号后的值更改为纯文本。
        保存并关闭文件。
        稍后在此任务中重新启动服务器时，将使用指定的定制密钥重新加密密码。
    编辑 bootstrap.properties 文件。
        转至 <OP_HOME>/wlp-usr/servers/<server_name>Server<#> 目录。
        生成 bootstrap.properties 文件的备份副本。
        在文本编辑器中打开 bootstrap.properties 文件。
        将等号后的以下密码值更改为纯文本。

        op.jdbc.password=<jdbc_password>
                             

        保存并关闭文件。
        稍后在此任务中重新启动服务器时，将使用定制加密密钥对密码进行重新加密。
    编辑 op-backup-restore.env 文件。
        转至 <OP_HOME>/aurora/bin 目录。
        生成 op-backup-restore.env 文件的备份副本。
        在文本编辑器中打开 op-backup-restore.env 文件。
        将等号后的以下密码值更改为纯文本。

        IBM® Db2®
            DB_OP_PWD: 输入 OpenPages 数据库的模式所有者的密码。
        Oracle
                DB_SYSTEM_PWD: 输入 OpenPages 数据库的 SYSTEM 用户的密码。
                DB_SYS_PWD: 输入数据库 OpenPages 的 DBA 用户的密码。
                DB_OP_PWD: 输入 OpenPages 数据库的模式所有者的密码。

        保存并关闭文件。
    使用指定的定制加密密钥对 op-backup-restore.env 文件中的密码进行重新加密。
        转至 <OP_HOME>/aurora/bin 目录。
        运行以下命令：

        Windows

            OPBackup.cmd secure

        Linux

            ./OPBackup.sh secure

        在文本编辑器中打开 op-backup-restore.env 文件，并验证密码是否已加密。
    如果您正在使用水平集群，请在集群中的每个应用程序服务器上执行步骤 2-6。
    启动所有 OpenPages 应用程序服务器，即 admin 和非 admin。
    请参阅 启动应用程序服务器。

结果

使用您在 keystore.properties 文件中指定的定制加密密钥对密码进行加密。
